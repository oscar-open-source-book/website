## 一、先复盘：五年年度活动留下的脉络

写海报之前先把历年翻了一遍，否则「征集」会变成空喊。

| 年份 | 活动日 | 主题 / 核心问题 | 当时的做法 |
|---|---|---|---|
| 2022 | 12-24 | 年终总结 | 《码出自由：如何思考开源的文化》+ 小组年度总结 |
| 2023 | 12-23 | 一年的读书心得 | 微软中国提供场地，KCC 北京、开源之法与经济联办 |
| 2024 | 2025-01-04 | **六周年庆** | 上午爬香山、下午分享、晚上宴会，六人筹备组 |
| 2025 | 2026-01-17 | **「感受变革！读书，读世界这本大书」** | 首次把方法论摆上台面：大模型助力阅读 + 如何面对变化 |
| 2026 | **2027-01-09** | **「读书还值得吗？」** | 首次质疑活动本身 |

**脉络读出来三件事：**

1. **前三年是「总结 + 展望」，第五年才第一次问方法论，第六年第一次问「还值得吗」。** 问题一年比一年尖锐——不是越来越丧，是越来越敢正面看。
2. **六年来赞助、场地、筹备都是同一批人在兜。** 王厚连续多年出资，振华赞助咖啡与书籍，微软中国与由新书店提供场地，KCC 北京与「开源之法与经济」长期联办。
3. **规模没怎么涨，但问题在变硬。** 这是这一集海报的起点。

## 二、第一集的立意：把「共读」当成一件公共财产

**不要征集「更多人来听」，要征集「下一年的议程由谁来定」。**

这六年做的不是一件事，是一个**持续投入才得以存在的东西**：

- 有人出钱（多年连续，不是一次性）
- 有人出场地
- 有人出时间读、出时间讲
- 有人在每年一月把大家叫到一起

这些东西合起来，就是一个小型的**知识公地**——它不像软件能被 fork，但只要有一年没人接，它就断了。

所以第一集要说的不是「来参加」，而是：

> **这件事做了六年。第七年的议程，还没人写。**

### 主标语（三档，推荐第一档）

**A（推荐）**
```
读书还值得吗
这个问题，我们留给下一个人来答
```

**B（更克制）**
```
第六年结束了
第七年的议程，还没人写
```

**C（更锋利）**
```
六年了
一直是同一批人在兜
2027 年 1 月 9 日，换你试试
```

## 三、视觉方向：一张被反复翻开的桌面

### 为什么是「桌面」而不是「书」

书是结果。**桌面才是过程**——它看得见被使用过的痕迹：桌角磨白、杯印、几道划痕、笔尖压出的凹点。

这正是「公共财产」的视觉化：**一件东西之所以是公共的，是因为它被很多次使用，且下次还能被使用。**

### 主视觉：一张空了的旧木桌

一张长条木桌，从画面中部横向铺开。桌面上摊开着两三本书，一些合着、一些反扣着，位置不整齐——像刚有人离席。桌上散着纸片、一支笔、几个不同材质的杯子（陶瓷、玻璃、纸杯——**不同的人用不同的杯子，这是关键细节**）。

**没有人。椅子被推开一半。**

光线从左侧斜射进来，把桌面的木纹、杯底的水痕、书页的边缘照得很清楚。

这不是「读书会的照片」，是**「刚结束的一场读书会」**。空着的位置不是没有人，是**下一个人还没坐下**。

### 备选 B：一排年份刻痕

一张旧木桌的桌面特写，左上角到右下角用刀刻着六个年份：`2022 2023 2024 2025 2026 ?`

最后一格是空的，刀尖停在旁边。

—— 更直接，但「刻痕」这个符号有点重，容易读成纪念而非邀请。

### 备选 C：摊开的书页上有很多手写的批注

一本摊开的书，页边空白处密密麻麻写着不同笔迹的批注（不同颜色、不同粗细）——**同一本书被很多人读过**。下一页还是空白的。

—— 这个最贴「公共财产」，但也最依赖 AI 渲染手写字迹，风险高。

**推荐 A**：木桌 + 不同的杯子 + 被推开的椅子，三层信息（被使用过 / 很多人用过 / 位置还空着）一次讲完，且不需要 AI 写字。

## 五、出图后必做的核对

AI 一定会把中文写错几处，逐字看：

| 必核项 | 常见错误 |
|---|---|
| **适兕** 的「兕」 | 最高频错字：会写成「适咒」「遏兕」「适兄」 |
| **「共读」** | 可能被写成「共续」「共卖」 |
| **「议程」** | 可能写成「议成」 |
| **日期 2027.01.09 周六** | 已用 `date` 核实确实是周六；别让它改成周日 |
| **URL** | `osbook.opensourceway.blog/cfp` 必须逐字符对 |
| **二维码位** | 必须是**纯色空白方块**，里面不能有任何 AI 画的图案 |
| 杯子数量 | 应该 3-4 个且**材质不同**——如果全变成一样的杯子，「不同的人」这层意思就没了 |

### 二维码必须后期贴

```bash
cd ~/developing/oscar-website
python3 scripts/poster-qr.py <海报.png> "https://osbook.opensourceway.blog/cfp/" \
  --size 320 --margin 60
```

贴完**实扫验证**：手机相机对准 → 应打开 CFP 提交页。

> 注意：这一集二维码指向 **/cfp/**（征集议程），不是报名页。报名入口留在活动页面里。

## 六、本系列的后续集（先记账，别急着做）

第一集立的是「公共财产 + 征集议程」。后面几集建议按这个顺序推进，每一集解决一个具体的「怎么参与」：

| 集 | 大概时间 | 征集对象 | 一句话 |
|---|---|---|---|
| **1（本集）** | 11 月中 | 议程 / 议题 | 第七年的议程还没人写 |
| 2 | 11 月底 | 分享人 | 你今年读到的那本改变想法的书 |
| 3 | 12 月初 | 圆桌参与者 | 「放弃还是继续」需要有人站两边 |
| 4 | 12 月中 | 场地 / 赞助 | 六年的桌子都是别人借的 |
| 5 | 12 月底 | 远程参与者 | 来不了现场，也能占一个位置 |
| 6 | 1 月初 | 全体 | 最后一次提醒 + 议程定稿 |

**每集视觉上要能认出来是一套**：同一张木桌、同一束左侧斜光、同一套配色，只换桌面上的东西和文案。这样六张放在一起是一个系列，而不是六张互不相干的图。

## 七、禁忌清单

| 别做 | 为什么 |
|---|---|
| 画成一屋子人围坐读书 | 那是活动的照片，不是征集海报；且一画人脸就失去「位置留给你」的意思 |
| 画整齐的书堆 / 图书馆书架 | 太干净，读成「知识的殿堂」，而这件事六年来的特点是**朴素、被使用过** |
| 加「科技感」蓝光、电路板、二进制 | 与「读书会」气质冲突，也是 AI 廉价感重灾区 |
| 画成纪念册 / 周年庆典风 | 这一集是征集，不是庆祝；喜庆元素会削弱「还没人写」的紧迫感 |
| 写大段议程或历史 | 海报只负责让人停下来；细节留给活动页 |
| 用「教授」「专家」这类称谓 | 「开源之道」的主张：title 留在读书会门外 |
| 让 AI 自由发挥中文 | 所有文案逐字给定，不给它创作空间 |
| 一次不满意就重写整段 | 只改出错的那一段，先判断问题在 VISUAL 还是 TYPOGRAPHY |

## 八、成图参数

- **比例**：3:4 竖版（1024×1365 或 1536×2048）
- **风格**：photorealistic editorial photography（不要 illustration / 3D render）
- **中文**：Source Han Serif / Noto Serif CJK 观感
- **主色**：暖白 `#F5F0E8` + 深墨 `#2C2A26` + 古铜 `#B4A078` + 普鲁士蓝 `#1B3B6B`
- **留白**：下半部至少 45% 干净，给文字和二维码
- **一句话检验**：把这张图给人看三秒，他能不能说出「这里曾经有人读过书，现在位置空着」——说不出就是 VISUAL 段要改。

## 二、设计判断：这次不该画「读书」

前几场的海报画的是「书」——一本书、书堆、地基。这次不行。

因为这一场的结构不是「读一本书」，而是**两个方向的判断撞在一起**：

- 《Peer Production》问：**人类为什么能协作？**（自发的、非雇佣的、非市场的）
- 《超级趋势》问：**机器接手 99% 脑力劳动之后，人还剩下什么？**

一个往「人多力量大」走，一个往「人被替换」走。中间那场 battle，就是把这两个判断摆到桌上对撞。

所以视觉的核心不是「书」，是**两个东西相对而立**。

### 主视觉：两张椅子，一张空着

一张长桌前，两把相对的椅子。桌上摊着两本书，一本翻开着，一本合着压着一支笔。
窗外是傍晚的天光。**没有人。**

空着的椅子不是「缺席」，是**位置留着**——既指向辩论的两个立场，
也指向那个还在「征集中」的时段。谁都可以坐下来。

### 备选 B：天平

一架旧式的双盘天平，左盘放一本厚书，右盘放一台关着的笔记本电脑。
天平微微倾斜，但没有倒。背景是一面素墙，光从侧面来。

—— 直接对应「人类协作 vs 机器替代」的称量感。风险是「天平」这个符号有点太直白。

### 备选 C：翻开的书页被光劈成两半

一本摊开的厚书，页面上落着一道锐利的斜光，把页面切成明暗两半。
暗的一侧几乎看不见字，亮的一侧字迹清晰。

—— 最抽象，也最像「辩论」。但少了「人」的暗示。

**推荐 A**：它同时容纳了「书」「对撞」「位置留着」三层意思，而且不需要画人脸。

## 六、出图后必做的核对

AI 生成中文一定会出错，这不是「可能」，是「一定」。**逐字核**：

| 必核项 | 检查方法 |
|---|---|
| **「适兕」的「兕」** | 最常见的错字：会写成「适咒」「遏兕」「适兄」。放大到 200% 逐笔看 |
| **「莅」** | 甘莅豪的「莅」，易错成「笠」「位」 |
| **「赵」云虎** | 姓氏不能错 |
| **「庄」表伟** | 不能写成「庄表委」 |
| **日期** | 必须是 **2026.12.19 周六** —— 12 月 19 日确实是周六，不要被模型改成周日 |
| **场地** | 「普陀校区」四个字必须齐全，不能只写「华东师范大学」 |
| **「辩论 battle」** | battle 是本场唯一允许出现的英文 |
| **二维码位** | 必须是**纯色空白方块**，里面不能有任何 AI 画的图案 |

### 二维码必须后期贴，禁止 AI 画

AI 画的二维码**结构不合法，永远扫不出来**。提示词里让它留一个空白方块，
出图后用脚本把真码融进去：

```bash
cd ~/developing/oscar-website
python3 scripts/poster-qr.py <海报图.png> "https://osbook.opensourceway.blog/signup/2026-12-19/" \
  --size 320 --margin 60
```

贴完**必须实扫验证**：手机相机对准 → 应打开报名页 → 页面标题显示
「报名 · 「OSCAR·开源之书·共读」上海站 2026-12-19」。

## 七、提示词禁忌清单（每次都在踩的坑）

| 别做 | 为什么 |
|---|---|
| 让 AI 画二维码 | 结构不合法，永远扫不出 |
| 出现人脸/手 | 一画脸，整张图的「安静感」立刻崩塌 |
| 加「科技感」蓝光、电路板、二进制 | 和「读书会」气质冲突，且是 AI 廉价感的重灾区 |
| 画机器人/仿生人 | 这一场谈的是「人的位置」，画机器人就把问题窄化成科幻 |
| 写大段议程 | 海报是吸引人停下，不是日程表；议程留给活动页 |
| 用「教授」称谓 | 「开源之道」的主张：title 留在读书会门外 |
| 让 AI 自由发挥文案 | 所有中文必须逐字给定，不给它创作空间 |
| 一次不满意就重写整个提示词 | 只改出错的那一段（先看是不是 VISUAL 段的问题） |

// RELEASE Kubernetes 1.24 CORE CHANGES

Kubernetes 1.24 延续了工程成熟度提升路线，移除技术债、增强 Windows 支持、优化调度器， 对于运营生产级集群的团队而言，这是一次值得重点关注的升级。

FEATURE 01
InTree 插件迁移
CSI 和 CNI InTree 存储网络插件正式移除，加速生态向独立 Operator 模式演进，解耦核心组件。
FEATURE 02
Windows 容器支持
Windows 节点增强，容器运行时和网络插件获得更多原生支持，生产部署路径更清晰。
v1.24 · HELM
FEATURE 03
调度器改进
调度器框架增强，支持更灵活的调度策略与插件扩展机制，复杂场景编排更可控。
FEATURE 04
Security Context
Pod 安全策略逐步走向成熟，Seccomp 默认 Profile 进入 Beta，容器安全基线进一步夯实。
多项
GA 特性 含 Windows 节点、调度器扩展等核心能力正式稳定
50+
移除特性 废弃 API 与 InTree 插件被移除，技术债大幅削减

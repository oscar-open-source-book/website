// PERMISSIVE
MIT
最简宽松协议，仅保留版权声明，允许任意使用、修改、分发与商用。
自由商用
无需开源衍生
// PERMISSIVE +
Apache 2.0
宽松协议，额外明确专利授权，要求保留通知文件，鼓励回馈社区。
专利授权
保留版权声明
// COPIELEFT
GPL
强 copyleft，衍生作品必须以相同许可证开源，保障软件自由的传播链。
衍生须开源
自由连锁传播
许可证决定代码使用与分发的边界：从宽松型到 copyleft 型，越靠右，对衍生作品的自由约束越强，是构建开放生态的底层法律契约。

推荐的开源阅读路径
OPEN SOURCE · READING PATH
好的阅读路径能显著降低学习者的试错成本。coases-penguin 项目在海量书籍资源基础上，为不同阶段的开发者提炼出从入门到专精的推荐路线——让每一位新加入社区的开发者，都能找到属于自己的起点与方向。
STAGE 01
入门阶段
从 Hello World 类书籍入手，建立编程基础与开源工具使用习惯，完成从 0 到 1 的迈出。
STAGE 02
进阶阶段
深入理解计算机系统、算法设计与分布式架构原理，夯实工程能力的基本盘。
STAGE 03
专业方向
根据岗位选择 Web 后端、数据工程、安全或 DevOps 等专精书籍，走向纵深。
STAGE 04
文化修养
阅读开源治理、敏捷开发与技术领导力书籍，提升工程视野与社区格局。

ROADMAP
入门 → 进阶 → 专业 → 修养 · 由浅入深，层层递进
从入门到专精，每一步都有书相伴。

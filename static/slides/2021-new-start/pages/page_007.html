> 新人上手学习路径

STEP-BY-STEP GUIDE

对每一位想踏入开源的新人来说，最大的障碍往往不是技术，而是第一步。这一章为你梳理一条清晰、可执行的上手路径，让开源之旅从今天开始。

▷▷ FOUR-STEP ROADMAP
0% ─── 25% ─── 50% ─── 75% ─── 100%
01
🌐
STEP 01
选好平台
从 GitHub 开始，关注感兴趣的仓库，从 Readme 和 Issue 了解项目全貌。
02
💻
STEP 02

本地克隆代码，运行测试，理解项目结构与开发流程。
03
📝
STEP 03
找个小 Issue
从 good first issue 或文档修正入手，完成第一笔 PR 提交。
04
👥
STEP 04
加入社区
参与 Discord、微信群、邮件列表，找到志同道合的伙伴。

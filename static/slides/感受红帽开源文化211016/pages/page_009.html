开源即活教科书 · A Living Textbook
开源学习的最佳方式，就是动手加阅读——从读懂一篇 README 开始，到追踪一段代码的演变，再到理解一个社区的治理规则。开源世界本身就是一部活教科书，每一次阅读都是一次与世界级工程师的对话，每一次思考都在构筑属于自己的知识阶梯。
📚 书目卡片 · 四维阅读矩阵 FOUR DIMENSIONS
01 CLASSIC · 经典著作 必读三部曲 《开源攻略》《大教堂与集市》《我的开源宣言》是必读三部曲，构筑开源理念的精神地基。
02 DOCS · 文档即学习 以文档为入口 阅读开源项目的 README、CONTRIBUTING、DESIGN 文档是最直接的入门方式，让代码会说话。
03 ARCHAEOLOGY · 代码考古 追踪代码演变 追踪一个功能从 Issue 到 Merge 的完整流程，理解工程协作的真实肌理与决策权衡。
04 CROSSOVER · 跨界阅读 建立系统认知 涉猎社区治理 · 开源法务 · 商业模式，跳出纯技术视角，建立系统性认知。

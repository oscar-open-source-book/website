SOCIAL ARCHITECTURE · 03

社区文化的三个层次

社区文化不是一维的，它有表层仪式、中层规范和深层价值观三个层次。表层最容易模仿，深层最难改变。一个项目的成功往往不是靠某个功能，而是靠这三个层次是否协调一致。

01 表层仪式感 SURFACE

社区最容易感知、也最容易被模仿的可见外在仪式，是文化的外显符号。

  • Release 版本号与发版公告
  • 版本号命名规范（语义化 / 日期制）
  • 社区会议 / All-Hands 的固定节奏
  • Logo、配色、文档首页的视觉一致性

02 中层协作规范 MIDDLE

制度化但灵活的行为规范，规定了协作的默认方式。

  • Issue 模板与 Label 分类体系
  • PR 审查流程与 Review 门槛
  • 响应时间约定（SLA / 优先级）
  • Code of Conduct 与争议处理流程
可制度 · 需共识 文化骨架
03 深层价值观 DEEP

社区的底层信仰与判断标准，决定社区天花板。

  • 是否欢迎新手、是否有耐心回答"蠢问题"
  • 是否包容技术分歧与路线辩论
  • 是否重视文档与知识沉淀
  • 贡献者是被视为"劳动力"还是"共同体成员"

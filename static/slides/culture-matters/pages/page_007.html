// 01
写一份行为准则
CODE_OF_CONDUCT 不是形式主义，而是告诉贡献者我们欢迎什么样的人、反对什么样的行为
// 02
设立新人友好标签
在 Issue 系统中标记 good-first-issue 和 help-wanted，让新贡献者有明确的切入点
// 03
建立响应 SLA
承诺在 48 小时内响应 Issue 和 PR，即使只是简单回复已收到
// 04
定期社区复盘
每季度回顾一次社区健康度，包括新贡献者数量、响应时间趋势、满意度调查
// 05
重视文档质量
README、CONTRIBUTING、DEVELOPMENT 指南是文化的第一个触点，值得持续投入
// 06
包容不同表达方式
不是所有人都擅长 Git 和英语，允许邮件、中文 PR 描述、语音会议等多种参与方式

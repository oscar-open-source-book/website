协作新原则

好的开源社区不仅需要好的代码，更需要好的文化。以下四条软性原则，共同守护社区长久的生命力。

PRINCIPLE 01

包容与尊重

无论经验深浅，每位贡献者都应得到平等对待和及时回应，让每个声音都被听见。

PRINCIPLE 02

透明决策

重大方向变更需通过公开讨论达成共识，让每个人都能了解决策逻辑，避免暗箱操作。

PRINCIPLE 03

文档先行

新项目启动前先完善 README 与贡献指南，让新人一看就懂，大幅降低入门门槛。

PRINCIPLE 04

及时反馈

所有 Issue 与 PR 应在约定时限内得到回应，让贡献者感受到重视，持续维护社区参与热情。

四条原则互为支撑，共同守护开源社区的长久生命力——让协作更有温度，让贡献更有回响。

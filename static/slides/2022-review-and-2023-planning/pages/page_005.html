重点书目解读

每一本经典都蕴含着跨越时代的智慧
01 / OPEN SOURCE
Linus 定律
Given enough eyeballs, all bugs are shallow
充分多的眼盯之下，没有 bug 能隐藏——开源协作的底层逻辑，众包的智慧胜过个体的精雕细琢。
"足够多的眼球下，一切问题皆是肤浅"
01
02 / CRAFTSMANSHIP
整洁代码哲学
Code is read more often than it is written
好的代码是写给人看的——命名、函数、注释各有其法，代码即文档，简洁即力量。
"代码是写给人看的，只是顺便让机器执行"
02
03 / DISTRIBUTED SYSTEM
分布式三定理
Consistency · Availability · Partition Tolerance
CAP 权衡贯穿所有系统设计决策——一致性与可用性必须取舍，没有免费的午餐，只有合适的妥协。
"三者不可兼得，选择即架构"
03
04 / PROJECT MANAGEMENT
Brooks 定律
Adding manpower to a late project makes it later
向延期项目增加人手只会让项目更加延期——沟通成本非线性增长，这是管理本质的悖论。
"向延期的项目加人只会让它更延期"

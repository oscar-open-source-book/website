04 CORE TENETS

开源的四大核心原则.

四大原则共同构成开源许可证的核心内容，不仅是法律条款，更是一种关于知识共享的哲学主张——软件应像知识一样自由流动，而非被锁在商业围墙之内。由此催生了 GPL、MIT、Apache 等各具特色的许可证家族，塑造了现代软件开发的基本范式。

FOUR FREEDOMS
01 / FREEDOM 0

自由使用

任何目的均可使用开源软件，不受商业或非商业场景限制。无论个人学习、企业商用还是公益项目，皆在法律框架下拥有同等使用权利。
USE FOR ANY PURPOSE
02 / FREEDOM 1

自由学习

源代码完全开放，任何人都可阅读、研究其工作原理与实现逻辑。代码即文档，每一行注释都是技术教育的天然课堂，孕育无数创新者。
STUDY THE SOURCE
03 / FREEDOM 2

自由修改

可根据自身需求修改代码逻辑，也可将修改后的版本重新分发给他人。这种"取用—改造—回馈"的模式构成了持续创新的反馈循环。
REVISION & INNOVATION
04 / FREEDOM 3

自由分发

原始版本或修改后的衍生版本均可自由传播给任何人，无需额外授权。分发的自由保障了社区持续生长与生态多样性繁荣。

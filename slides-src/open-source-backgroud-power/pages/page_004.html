关键里程碑事件

1991 — 2018

从1991年Linux内核的一个帖子，到2008年GitHub上线开启的协作新时代，开源的关键里程碑串起了一条从个人实验到全球基础设施的弧线

1991
Linux 内核
Linus 在 comp.os.minix 发帖宣布 Linux 内核，两个月内全球数千贡献者加入
1993
Apache HTTP Server
Apache HTTP Server 发布，迅速成为互联网主力 Web 服务器软件
2003
Git 发布
Linus 为 Linux 内核开发分布式版本控制工具 Git，重塑全球协作开发模式
2008
GitHub 上线
把开源协作推到云端，让 fork 与 pull request 成为开发者的日常语言
2018
企业拥抱开源
微软 CEO 纳德拉宣布微软拥抱开源，GitHub 收购完成后成为行业基础设施

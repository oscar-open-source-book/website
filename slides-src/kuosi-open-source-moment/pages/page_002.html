01 / CORE
开放共享
源代码自由访问与修改，让知识不再被高墙隔绝。每一次贡献都在打破壁垒，让信息流动的边界不断外扩。
02 / CORE
协作共生
全球贡献者共同打磨项目，众包智慧驱动创新。每个人都是网络中的节点，协作让平凡汇聚为非凡。
03 / CORE
透明可信
代码与决策公开可审计，建立基于信任的协作生态。阳光下没有秘密，透明是信任最坚实的基石。

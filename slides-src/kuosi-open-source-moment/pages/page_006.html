READING TRIAD · 阅读三要素
选材
·

01 / SELECT
选材有度
从经典著作到前沿博客，按需筛选高质量阅读材料，以质量驱动阅读深度。
02 / RECORD
记录成法
用自己的语言重写要点，形成可检索、可复用的笔记体系，让知识沉淀为资产。
03 / LINK
链接思维
将新知识与既有认知网络连接，构建个人知识图谱，让孤岛信息产生共振。
◆ NOTE
阅读的质量取决于选材与记录的方式。开源世界的优质输入来源广泛——官方文档、技术博客、书籍、Issue 讨论——关键在于建立属于自己的记录与链接方法，让每次阅读都成为知识网络的新节点。

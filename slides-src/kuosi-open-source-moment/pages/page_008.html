社 区 实 践 指 南

参与开源社区是一个阶梯式成长的过程，四阶段路径： 围观→贡献→维护→发起，每一步都在积累技术能力与社区影响力
01
LEVEL · 入门
key action: observe
参与讨论
从 Issue 和 Discussion 入手，理解项目社区的文化氛围与协作节奏，建立对代码库和生态的基本认知。
# 阅读 Issue # 参与 Discussion # 熟悉社区
L1
25%
02
LEVEL · 进阶
key action: contribute
提交 PR
从修复文档错别字到实现完整功能，逐步提升贡献的复杂度与影响力。每一次 Pull Request 都是对个人技术能力与代码审校能力的实战打磨。
# 文档修正 # Bug 修复 # 功能实现 # Code Review
L2
50%
03
LEVEL · 高阶
key action: maintain
维护项目
成为维护者需要技术判断力与社区沟通能力，是最高阶的参与形式。你需要把控项目方向、评审贡献、协调分歧，在技术决策与社区治理之间取得平衡。
# 技术决策 # 社区治理 # 版本管理 # Release
L3
75%
04
LEVEL · 创造
key action: create
发起项目
将积累的洞察与经验转化为自己的开源项目，完成从消费者到创造者的身份转变。你不仅是技术的实践者，更是新生态的奠基人，用自己的项目为社区贡献价值。
# 洞察转化 # 架构设计 # 生态建设 # 从零到一 # 开源领导者

100%

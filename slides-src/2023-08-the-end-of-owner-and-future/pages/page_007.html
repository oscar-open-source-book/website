PAGE 07 · FRAMEWORK

所有权的三种解构

将"所有权"拆解为代码、治理、社区三个层次，是理解开源项目演化的关键框架；代码可以被提交，治理可以被设计，但社区认同感无法被强制赋予——三者之间的动态平衡，才决定了项目的真正归属。

代码所有权 谁写了代码 ≠ 谁拥有代码
治理所有权 决策权的委托、分散与制度化
社区所有权 超越任何个人的社会所有权
LAYER · 核心 代码是底层资产，许可证
重新定义智力成果的流转
LAYER · 中层 治理是决策的骨架，
需清晰的边界与制衡
LAYER · 外层 社区是认同的场域，
无法被强制赋予
01 / CODE
代码所有权

谁写了代码并不等于谁拥有代码，许可证框架重新定义了智力成果的归属与流转。

02 / GOVERNANCE
治理所有权

决策权可以被委托、被分散、被制度化，但必须有清晰的边界与制衡机制。

03 / COMMUNITY
社区所有权

用户、贡献者、赞助商共同构成了项目的社会所有权，超越任何个人。

04 / TENSION
三者张力

当三者方向不一致时项目便会陷入内耗或分裂，找到平衡点是治理的核心艺术。

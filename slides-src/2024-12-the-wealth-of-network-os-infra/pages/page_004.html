主流开源网络OS按使用场景大致分为三类——面向数据中心白盒交换机的 SONiC 与 ONL、面向广域网与 SD-WAN的 VyOS、以及面向电信转发面的 Cloudnet+ 等方案；而 FRRouting 作为共同的路由协议守护进程集合，把这些方案在控制面上串联起来。

01
SONiC
Software for Open Networking in the Cloud
数据中心 白盒交换机 模块化
项目定位
由 Microsoft 发起、社区共建的模块化网络操作系统；以容器化微服务架构编排交换面与路由面，成为白盒交换机与数据中心网络的事实标配。
典型用户：Microsoft Azure、Facebook / Meta、Arista、Nvidia、戴尔、思科（白盒系列）
02
VyOS
Enterprise Routing on Linux
广域网 SD-WAN 路由全栈
项目定位
基于 Linux 内核 的企业级路由器；BGP / OSPF / IS-IS / BFD 全协议栈齐备，配合防火墙、VPN 与 QoS，是分支互联与 SD-WAN 场景的利器。
典型用户：中小企业分支机构、MSP / ISP、SD-WAN 服务商、企业边缘互联
03
Open Network Linux
Arista Community-Edition OS
数据中心 企业级 完整 OS
项目定位
由 Arista Networks 开源的完整交换操作系统，与 Arista EOS 同源；面向 企业级数据中心，提供生产级稳定性与全协议特性，社区版可持续迭代。
典型用户：Arista 合作伙伴、企业数据中心、白盒厂商、教育与研究实验室
04
ONL & Cloudnet+
Carrier-Grade Forwarding Plane
电信转发面 运营商主导 云化网络
项目定位
ONL（由 Dell、Nvidia、VMware 等电信侧厂商共建）与 Cloudnet+（中国信通院主导）代表运营商阵营的开源方向：前者聚焦 白盒数据中心交换机的操作系统，后者面向 电信级转发面与云化网络，覆盖 vRouter、vSwitch、SDN 网关等场景。
典型用户：中国移动 / 电信 / 联通、欧洲电信运营联盟、大型政企云网络、SDN 厂商联合生态
05
FRRouting
The Common Routing Control Plane
控制面 守护进程集合 跨 OS 通用
项目定位
由思科 Quagga 与 Zebra 演化而来的路由协议守护进程集合：bgpd、ospfd、isisd、zebra、bfd、pimd… 以模块化、事件驱动方式运行，支撑上述各 OS 的控制面，是开源网络世界事实上的控制面通用组件。
典型用户：SONiC / VyOS / ONL 内建调用；Linux 主机路由器、网络功能虚拟化 (NFV)、SDN 控制器南向对接
叙事主线｜ 五类方案虽各有所专，但都依赖 FRRouting 提供的路由协议守护进程 —— 转发面分立、控制面同源，是当代开源网络OS图谱最耐人寻味的结构特征。

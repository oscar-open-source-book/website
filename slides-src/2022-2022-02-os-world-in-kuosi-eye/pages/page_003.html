// Chapter · 2022.02 Release: Feb 24, 2022
Go 1.18 是 2022 年 2 月最受瞩目的开源发布之一
泛型补齐了 Go 语言最后一块被社区长期诟病的短板——集合库、算法库、序列化框架等通用代码终于可以用统一接口表达，不必再重复编写多套具体类型版本。

Workspaces 等新机制显著改善了开发者日常体验，让大型多模块仓库的本地联调从"手工 replace 地狱"回归简洁。同时引入 match 默认赋值，补齐了控制流中一个长期缺失的小但高频的语言糖。
> generics_in_action.go
func Filter<T any>(slice []T, pred func(T) bool) []T { var result []T for _, v := range slice { if pred(v) { result = append(result, v) } } return result } // 编译期展开 · 零运行时开销

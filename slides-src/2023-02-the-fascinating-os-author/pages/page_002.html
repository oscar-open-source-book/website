// OPEN SOURCE × READING

开源与阅读

为什么开源社区需要持续阅读与分享
在代码与人之间，阅读架起理解与传承的桥梁

1,400万+ 全球开源贡献者
100万+ 年度新增开源项目
KEY PILLARS · 三大核心
01 — ITERATION
知识迭代
开源生态每年涌现大量新框架与工具，阅读是保持技术视野的必要手段，持续输入才能不被时代淘汰。
02 — HERITAGE
文化传承
开源精神需要书籍、文章与布道者来传播，让后来者理解其价值与历史，让理念薪火相传。
03 — CONNECTION
社区连接
阅读分享活动是开发者社区维系情感与知识纽带的重要场景，让个体成长与群体进步同步发生。

// CORE CONCEPT · FSF

核心概念：四个自由

—— 自由软件基金会（FSF） 提出的衡量开源许可证的核心标尺，四项自由缺一不可。
FSF
0
FREEDOM ZERO · RUN
运行自由
用户可以出于任何目的运行程序，不受场景、用途或商业性质的限制。这是自由软件最基本、也是最具实践意义的起点。
RUN 任意目的
// 0x00
1
FREEDOM ONE · STUDY
研究自由
用户可以获取程序的源代码，研究其内部逻辑与设计思想，从而真正理解它"为何如此工作"——知识透明是信任的前提。
STUDY 源码透明
// 0x01
2
FREEDOM TWO · MODIFY
修改自由
用户可根据自身需求修改源代码，对修改后的衍生版本拥有完整的控制权与处置权——软件应服务于人，而非相反。
MODIFY 衍生版本
// 0x10
3
FREEDOM THREE · REDISTRIBUTE
分发自由
用户可自由分发原始版本与修改版本，前提是遵守许可证附加的传播条件——自由得以传递，社区方能生长。
SHARE 遵守条款
// 0x11
!
这四个自由并非无限放权，而是强调用户对软件应有的基本控制权——运行、研究、修改、分享；许可证的严格程度体现在对这四项自由的保留与附加条件上。

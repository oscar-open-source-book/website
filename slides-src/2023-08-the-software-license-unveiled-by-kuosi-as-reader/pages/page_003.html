CORE CONCEPT · 04 FREEDOMS

核心概念：四个自由

// The Four Freedoms — 衡量开源许可证的核心标尺
FSF · GNU
OPEN-SOURCE LICENSING
自由软件基金会（FSF）提出的 "四个自由" 是衡量开源许可证的核心标尺 —— 它们并非无限放权，而是强调用户对软件应有基本控制权：运行 · 研究 · 修改 · 分享。许可证的严格程度体现在对这四项自由的保留与附加条件上，构成了后续分类的基础坐标。
0
运行自由
RUN · The Freedom To Run
FREEDOM #0
用户可以出于任何目的运行程序，不受场景或用途限制——个人学习、商业部署、教育研究皆可。
RUN · PURPOSE-AGNOSTIC 0 / 3
1
研究自由
STUDY · The Freedom To Study
FREEDOM #1
用户可以获取源码、研究程序逻辑，以理解其工作原理——透明性是研究自由的前提。
STUDY · SOURCE-ACCESSIBLE 1 / 3
2
修改自由
MODIFY · The Freedom To Modify
FREEDOM #2
用户可根据自身需求修改源码，并对修改后的版本拥有完整权利——包括私有使用和内部部署。
MODIFY · FULL RIGHTS 2 / 3
3
分发自由
REDISTRIBUTE · The Freedom To Share
FREEDOM #3
用户可自由分发原始版和修改版，前提是遵守许可证附加条件——这是各许可证差异化的关键。
REDISTRIBUTE · LICENSE-GATED 3 / 3

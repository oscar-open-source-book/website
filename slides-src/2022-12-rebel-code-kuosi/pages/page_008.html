参与开源的实践路径

从旁观到参与、从跟随到引领——这是一条渐进成长的路径，每个阶段都有明确的行动目标与成长收益，关键在于保持持续投入的节奏。

1–3 月
01
BEGINNER
📖
入门：阅读与跟随 Reading & Observing
从阅读项目 README、Issue 讨论和 PR 评论开始，理解社区的沟通风格与技术要求，建立对开源协作的基本认知。
README Issue 讨论 PR 评论
1–3 月
02
ADVANCING
✏️
进阶：文档与小修 Docs & Minor Fixes
从翻译文档、修复拼写和补充示例等低门槛贡献入手，熟悉提交流程与代码规范，迈出第一步实际贡献。
翻译文档 拼写修复 补充示例
3–6 月
03
DEEP DIVE
🐛
深入：Issue 修复 Issue & Bug Fixing
认领 Good First Issue 或 Bug 标签，独立解决问题并经历完整的 Code Review 流程，积累实战经验与社区信任。
Good First Issue Bug 修复 Code Review
6–12 月
04
LEADER
⚙️
高级：特性与治理 Features & Governance
参与 RFC 讨论、提交特性 PR，逐步走向核心维护者甚至项目治理层角色，从贡献者成长为社区引领者。
RFC 讨论 特性 PR 社区治理

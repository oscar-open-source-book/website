从科学共同体到开源共同体
开源实现了批判机制的民主化与知识生产的去中心化，但需在开放与规范之间寻找新平衡
科学与开源：两种知识共同体的对话
01
知识生产革命
开源将默顿所描述的科学知识生产模式，扩展至软件工程的数字领域
02
同行评议的演化
从学术期刊的正式同行评议，到 GitHub 上公开的 Code Review，批判机制被民主化与实时化
03
科学民主化
开源降低了参与门槛，使非机构化个体也能参与高质量的知识创造与技术生产
04
局限与反思
开源无法完全替代正式科学体制，数据可复现性与同行问责仍需制度保障

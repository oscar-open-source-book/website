THE OPEN SOURCE SPIRIT
开源精神
Where code becomes commons.
开源精神并非一夜诞生。它从 Unix 时代的工程师互助开始，经 GNU 自由软件运动奠基，到 Linux、Apache、Mozilla 等社区走向全球化协作，最终形成今天以协议为契约、以社区为组织形式的文化。
— from Unix, GNU to the global commons —
Ⅰ. 从个人到社区

FROM PRIVATE TO COMMONS

开源把代码从私有资产推向公共知识，让知识跨越组织边界自由流转。

Ⅱ. 协议即契约

LICENSE AS CONTRACT

GPL、MIT、Apache 定义了共享的边界，为协作提供法律与道德的双重锚点。

Ⅲ. 共同作者

SHARED AUTHORSHIP

贡献者署名机制让每一次协作留下痕迹，也让集体创作有据可寻。

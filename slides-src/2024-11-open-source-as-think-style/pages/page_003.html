OPEN SOURCE · RETHINK

重新定义"开源"

OPENING THOUGHT

我们不再只问代码是否开放，而要问 知识是否被当作公共资源来对待。开源不再是一组许可协议，而是一种关于共享、透明与信任的思维方式。

01
📜

许可 ≠ 全部

GPL / Apache 只是外壳，真正内核是共享动机与协作规范。协议文本无法替代社区对"为什么打开"的一致理解。

License Motivation Norms
02
👁️

透明即默认

把决策过程、路线图、甚至失败都公开——这是开源社区的基本协议，而非可选的公关姿态。

Roadmap Decision Log Post-mortem
03
🤝

信任先于控制

信任机制靠代码审查、issue 讨论、维护者治理来建立——先建立可验证的信任，再谈规模与速度。

Code Review Issues Governance
04
🌐

公共性优先

以公共知识为目标，而非单一组织的私有资产。开源是共同维护的公共财，不属于任何一家公司。

Public Good Commons Non-captive

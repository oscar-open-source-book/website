Transaction Cost Economics · Coase 1937
交易成本的三重维度
市场并非零成本运行——搜寻信息 · 谈判决策 · 执行监督共同构成交易成本的三重维度；当企业内部协调比市场交易更便宜时，企业便会存在并扩张。
FRAMEWORK / 03
// DIMENSION   < 3 >

DIMENSION / 01
搜寻与信息
SEARCH & INFORMATION
发现合适的交易对象、评估价格与质量本身即需耗费大量资源。市场上没有免费的清单——每一次匹配、每一份比价、每一次尽职调查，都在为成交预付一笔隐性学费。
KEY · 匹配成本 · 比价成本 · 尽调成本
DIMENSION / 02
谈判与决策
NEGOTIATION & DECISION
每一次交易都需经过谈判、签约与博弈；条款来回拉锯、利益反复权衡，累积出高昂的制度成本。合同越复杂、博弈越充分，决策链路就越沉重。
KEY · 条款博弈 · 签约成本 · 制度摩擦
DIMENSION / 03
执行与监督
ENFORCEMENT & MONITORING
合同签署并非终点。履约需持续监控，违约风险悬而未决，一旦出现分歧便需仲裁与补救——这些事后支出同样计入交易成本的账本。
KEY · 履约监控 · 违约救济 · 争议仲裁

RESPONSE / 04
当 企业内部协调成本 < 市场交易成本 时，企业边界向外扩张——原本分散在市场中的交易，被纳入企业内部的命令与计划之中；反之则收缩。这是科斯命题对企业存在与边界的根本解释。

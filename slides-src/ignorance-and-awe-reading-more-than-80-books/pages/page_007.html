推荐书单精选

从八十多本书中精选四本作为重点推荐，它们分别代表工程素养、历史视野、商业智慧与认知科学四个维度，也是个人阅读旅程中影响最深的作品，每本都被反复阅读、持续补充笔记，多年后仍能获得新的启发。
01 工程素养
代码整洁之道
Clean Code — Robert C. Martin
工程素养的基础训练，读完后开始主动重构自己的代码和文档
— READING NOTE 001
02 历史视野
人类的群星闪耀时
Decisive Moments — Stefan Zweig
用历史的关键瞬间教会我们：决定命运的往往是短暂的瞬间
— READING NOTE 002
03 商业智慧
穷查理宝典
Poor Charlie's Almanack — Charlie Munger
跨学科思维与投资智慧的完美结合，启发构建多元思维模型
— READING NOTE 003
04 认知科学
思考，快与慢
Thinking, Fast and Slow — Daniel Kahneman
理解认知偏差的必读之作，改变了对自己决策方式的所有认识
— READING NOTE 004

CLASS Ⅰ 宽松型
代表 MIT / BSD / Apache
—— 最低约束
允许自由修改、分发与闭源商用，仅保留版权声明。是企业级项目最主流的默认选择，几乎零摩擦接入任何商业产品。
MITBSD-3Apache-2.0
CLASS Ⅱ 强 Copyleft
代表 GPLv2 / GPLv3
—— 强传染
任何衍生或链接作品均须以同等协议开源。对核心基础设施类项目保护力度最强，但与企业闭源需求存在根本冲突。
GPLv2GPLv3
CLASS Ⅲ 弱 Copyleft
代表 LGPL / MPL
—— 混合友好
介于两者之间：动态链接可商用，仅修改库本身需开源。为库型项目和插件生态提供了兼顾开放与商业的折中路径。
LGPL-2.1MPL-2.0
✦

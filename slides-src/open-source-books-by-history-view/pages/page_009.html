阅读方法论如何选书

书单再长，最终要落到个人成长路径上。好的阅读方法是把书当作地图，把开源项目当作目的地，在阅读与实践中不断校准方向。

📖 如何选书 HOW TO CHOOSE
01
按技术栈选
BY TECH STACK
🏗️
确定当前使用的语言与框架，优先选对应生态的经典作品与官方文档，从最贴合实战的内容入手。
语言生态 经典作品 官方文档
02
按阶段选
BY STAGE
📈
入门期看概念与教程，进阶期看原理与源码，资深期看治理与架构——不同阶段匹配不同深度的读物。
入门期 进阶期 资深期
03
按社区口碑选
BY COMMUNITY
⭐
关注 GitHub 星标、社区推荐榜单以及同领域从业者的真实反馈，让集体智慧帮你筛选高质量读物。
GitHub 星标 推荐榜单 同行反馈
04
搭配开源项目读
PAIR WITH OPEN-SOURCE
🔄
边读边跑对应开源项目，用代码验证书中观点，形成知行合一的闭环，让知识在实战中沉淀。
边读边跑 代码验证 知行合一

高效地从浩如烟海的开源读物中找到属于自己的那几本
